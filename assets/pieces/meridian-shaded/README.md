# Meridian Shaded

The Meridian Shaded chess-piece artwork was created by Martin Sedlák and is
published in the upstream `chess_svg_piece_sets` project. The upstream README
describes the Meridian design as copied from a 1952 German newspaper and this
variant as using shaded linear gradients. The author dedicates the artwork to
the public domain using the included CC0 dedication; the upstream project says
it may be bundled with programs, including commercial programs.

Upstream: <https://github.com/kmar/chess_svg_piece_sets>
Imported set: `meridian_shaded/`
Imported revision: `af40ea51e87eddee1ae7ee35ae312893a1271233`

The SVG source files and the exact upstream `LICENSE` text are retained in the
`source/` subdirectory. The twelve runtime PNGs are rendered directly from the
SVGs at 512x512 with librsvg. This is a development-time conversion; Gambitree
loads PNG and has no SVG runtime dependency. Gambitree's own GPL-3.0-or-later
license does not replace or change the artwork's upstream public-domain
dedication.
